# Research

The research directory records external technical evidence and AER interpretation.

## Layout

- `briefs/` — dated weekly research briefings.
- `papers/` — deeper notes for individual papers, projects or technical topics.

## Evidence convention

Clearly separate:
1. what a source claims,
2. what AER verified,
3. what AER infers,
4. what AER has experimentally measured.

Use stable links/identifiers such as DOI, arXiv ID, repository commit/tag and publication date whenever possible.
