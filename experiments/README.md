# Experiments

Every meaningful AER experiment should be reproducible.

Suggested experiment directory:

```text
experiments/<experiment-name>/
├── README.md
├── config/
├── scripts/
└── results/
```

An experiment README should record:
- hypothesis
- baseline
- independent/dependent variables
- environment and software versions
- dataset/scenario
- metrics
- run procedure
- results
- limitations
- conclusion
- regression tests created from failures
